## ADDED Requirements

### Requirement: 다크모드 토글
시스템은 사용자가 다크모드와 라이트모드를 수동으로 전환할 수 있어야 한다.
- 모든 화면(로그인, 회원가입, 팀선택, 칸반, 채팅)에 토글 버튼이 존재해야 함
- 칸반/채팅/팀선택: 헤더 우측에 버튼 배치
- 로그인/회원가입: 우상단 고정(fixed) 위치에 버튼 배치
- 라이트 → 다크 전환 시 버튼 아이콘: 🌙
- 다크 → 라이트 전환 시 버튼 아이콘: ☀️

#### Scenario: 라이트에서 다크로 전환
- **WHEN** 사용자가 🌙 버튼을 클릭
- **THEN** `<html>` 요소에 `dark` 클래스가 추가됨
- **THEN** 모든 UI 요소가 다크 테마로 즉시 전환됨
- **THEN** 버튼 아이콘이 ☀️로 변경됨

#### Scenario: 다크에서 라이트로 전환
- **WHEN** 사용자가 ☀️ 버튼을 클릭
- **THEN** `<html>` 요소에서 `dark` 클래스가 제거됨
- **THEN** 모든 UI 요소가 라이트 테마로 즉시 전환됨
- **THEN** 버튼 아이콘이 🌙로 변경됨

### Requirement: 다크모드 상태 유지
시스템은 사용자의 다크모드 선택을 localStorage에 저장하고, 다음 방문 시 복원해야 한다.

#### Scenario: 페이지 이동 후 상태 유지
- **WHEN** 다크모드 활성화 상태에서 다른 페이지로 이동
- **THEN** 이동한 페이지도 다크모드로 표시됨

#### Scenario: 새로고침 후 상태 복원
- **WHEN** 다크모드 활성화 상태에서 페이지를 새로고침
- **THEN** 페이지가 다크모드로 로드됨 (라이트로 깜빡이지 않음)

#### Scenario: 기본값 (최초 방문)
- **WHEN** localStorage에 저장된 테마 값이 없을 때
- **THEN** 라이트모드로 표시됨
